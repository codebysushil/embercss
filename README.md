### EmberCSS - Ignite Modern Web Interfaces.

A lightweight, utility-first + component CSS framework with modern CSS features, built in **Less**, optimized for speed, responsive design, dark mode, and container queries.

---

#### Core Features

- [x] Mobile-first
- [x] LessCSS source + compiled ember.min.css
- [x] CSS Variables
- [x] OKLCH color system
- [x] Light/Dark theme
- [x] Glassmorphism
- [x] Gradients colors
- [x] Container Queries
- [x] CSS Nesting
- [x] CSS Layers
- [x] Responsive utilities
- [x] Accessible components
- [x] Zero JavaScript required
- [x] Tiny build size (<40 KB minified target)
